IOT 2024 (SENAI)

Desenvolvi, no SENAI, um sistema IoT onde utilizei um ESP32 para coletar dados de sensores e enviá-los em formato JSON via MQTT para a AWS, garantindo uma comunicação segura com o uso de certificados e broker próprio. Também implementei uma dashboard interativa no Node-RED, rodando em uma instância EC2, permitindo o monitoramento e controle remoto dos dados em tempo real.

Cofrinho Digital (UNINTER)

Este trabalho consiste no desenvolvimento de um sistema de cofrinho digital em Java, que permite ao usuário gerenciar moedas de diferentes tipos, como dólar, euro e real. Através de um menu interativo no terminal, o usuário pode adicionar moedas ao cofrinho, remover valores específicos, listar todas as moedas armazenadas e visualizar o total convertido em reais.
